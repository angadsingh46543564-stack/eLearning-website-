# EduSphere - E-Learning Website Management System

Folder layout
- public/index.html          page markup
- public/style.css           all styles (dark/light theme)
- public/app.js              all application logic (courses, quizzes, AI video lessons, notes, backends)
- public/firebase-config.js  Firebase web config
- public/libs/               jsPDF (certificates) and QR code libraries
- firebase.json, .firebaserc, firestore.rules, firestore.indexes.json   Firebase settings

Deploy
1. npm install -g firebase-tools
2. firebase login
3. firebase deploy
